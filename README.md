# Обзор
Проект для автоматической сборки учебных Anki-карточек грамматики JLPT с ресурса Bunpro.
Перевод карточек производится нейросетью GPT-OSS-120B. Генерируются два набора карточек:

JP - RU (грамматика - значение)

RU - JP (значение - грамматика)


# Использование
Проект использует uv. После клонирования для настройки окружения достаточно написать 
```sh
uv sync
```

Запускается скрипт с main.py:
```sh
uv run main.py
```

# Источники
Bunpro - https://bunpro.jp - грамматика по уровням JLPT.
